# Manual de usuario

## Inicio

Abrir el sistema en:

```text
http://localhost:8080
```

## Crear sala

1. Escribir el nombre de la sala.
2. Escribir el nombre del responsable.
3. Presionar **Crear sala**.
4. Copiar el código de invitación generado.

## Unirse a una sala

1. Ingresar el código de sala.
2. Escribir el nombre del participante.
3. Presionar **Entrar / registrarme**.

## Registrar predicción

1. Seleccionar un partido de la lista.
2. Escribir los goles pronosticados para local y visitante.
3. Presionar **Guardar predicción**.

La predicción se puede actualizar mientras falten más de 10 minutos para el inicio del partido.

## Publicar resultado

1. En el partido correspondiente, ingresar el resultado oficial.
2. Presionar **Publicar resultado**.
3. Actualizar la tabla general.

## Revisar puntajes

La sección **Tabla general** muestra:

- Posición.
- Participante.
- Partidos evaluados.
- Puntos base + bonus por anticipación.
- Bonus por racha.
- Total acumulado.
